/ estándar SDD · plugin de Claude Code · v0.1.0

Nada se codea { sin spec } aprobada por ti.

tremen-sdd empaqueta una forma de construir software con IA: un equipo de roles con poderes separados, gates humanos donde importa, y hooks que convierten el método en regla — no en buena intención.

conoce al equipo → ver los flujos
/ 01 — la idea

La estructura se scriptea,
el juicio se escribe.

Todo lo mecánico — numerar specs, transicionar estados, regenerar el tablero — lo hacen scripts deterministas. La IA solo pone lo que solo ella puede poner: criterio. Y cada transición de estado queda auditada: quién, cuándo, desde dónde.

/ 02 — las tres patas
01 / proceso

Un pipeline con gates humanos.

Producto → arquitecto → implementador → verificador. Tú apruebas la spec, los ADRs y el merge. Todo lo demás corre solo — y para cuando debe parar: tres rojos seguidos y escala a ti.

ver los flujos
02 / enforcement

Hooks que no negocian.

Editar código sin spec aprobada: denegado. Tocar un documento de verdad sin ser su dueño: denegado. El linter en rojo vuelve como feedback. Fail-open: si algo raro pasa, nunca te dejan tirado.

¿por qué me bloqueó?
03 / evidencia

Cada CA con su prueba.

El ledger mapea cada criterio a su código, su test y su verificación. El verificador captura pantalla y vídeo, y ensambla un acta HTML autocontenida que puedes enseñar a quien haga falta.

/ 03 — instalar

Tres líneas y un proyecto que nace recto. 

# una vez, en tu máquina
claude plugin marketplace add tremen-dev/tremen-sdd
claude plugin install tremen-sdd@tremen-sdd

# en cada proyecto (nuevo o migración)
/sdd-init
